# Four-group paste retraction comparison — October 1, 2026

A single 32-pad comparison ran four consecutive eight-pad groups in 331 seconds total. The measured native stages completed and the run was recorded as verified. Each eight-pad group took approximately 41–48 seconds of active route time.

The groups varied fractional retraction amounts while keeping the declared 6-degree dose and the reviewed conditioning cycle fixed. Offline before/after image analysis found the 30% group had the most uniform 2D image-change descriptors in this one comparison. This is a preliminary observation from eight pads in one run; it does not establish a repeatable effect, calibrated paste volume, process capability, or a qualified recipe. The comparison remains exploratory and unqualified.

The analysis reports pixel-change area and equivalent 2D diameter within CAD-centered pad regions. These image measures can be affected by lighting, residue, glare, and image alignment; they are not measurements of deposited volume. The helper and focused tests are included as source for repeatable offline review.
